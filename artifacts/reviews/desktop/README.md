# 潮汐桌面端 UI 精修

设计方向：保留纸白、海松绿和潮线标识，让公开状态成为视觉中心，操作区紧凑、对齐且易读。

## 范围

- Go / Fyne 桌面端的概览、软件监听、偏好设置及添加 / 编辑软件弹窗。
- 保留现有字体、导航顺序、文案目录和采集、同步、配置保存流程。
- 默认窗口 720 × 560，最小窗口 600 × 460；较长内容滚动阅读。

## 视觉调整

- 通用图标 16，窗口控制图标 14，应用图标 24，应用图标背景 36；应用图标居中约束，避免随行高拉伸。
- 标题 22、状态 24、界面正文 13、辅助说明 12；文字组取消控件内边距，单独控制 4 / 8 / 12 / 16 的间距。
- 按钮与输入框统一内边距和 8 像素圆角，弹窗 / 卡片 12 像素圆角。
- 导航使用浅绿选中态，与实色保存主按钮区分；窗口控制与导航分行。
- 设置标签与输入控件沿列对齐，说明紧跟控件；应用列表按图标、名称、进程和操作排列。
- 页脚显示连接状态点、文字、最近同步和版本；状态不只依赖颜色表达。

## 动效与文案

沿用 Fyne 的悬停、按下和键盘焦点反馈，没有新增循环动画或入场位移。保留原有中英文案，没有增加装饰性文案，也没有删去隐私说明或规则提示。
