# 海湾小人：当前开发版本

用户已接受当前可爱卡通方向，并授权先接入游戏，外观继续迭代。

- 可编辑源：`cozy-avatar.blend`，Blender 4.5.15 LTS，贴图已内嵌。
- 网页资产：`public/assets/models/avatars/cozy-avatar-v1.glb`，2,321,528 字节，34,920 三角面、22 根骨骼、6 种材质。
- 动作：Idle、Walk、Run、Jump、Sit、Wave。Y 向上、朝向 +Z、脚底为原点，高约 2.1 个场景单位。
- `export.py` 可从当前源重新导出；改模后仍须重新执行 Blender 几何、动画和浏览器视觉检查。
- `qa/` 保存最终制作阶段的检查快照与运行验证；其中旧报告的 `game_ready: false` 表示完整美术生产验收尚未完成，不代表当前没有接入开发。

## 来源

项目原创参考图使用 ImageGen 生成，经用户认可后，通过 Hugging Face 上的 Microsoft TRELLIS.2 图生 3D，再在 Blender 中修整面部、重建服装与四肢、绑定骨骼和制作动作。当前资产没有使用之前试选的 Snow 等第三方人物模型。这里记录生成与制作来源，不把生成工具的代码许可证当作成品资产的授权声明。

## 当前能力与限制

本地玩家、远端玩家与合照共用此版本。每个实例独立骨骼、动画混合器和材质，共享几何与贴图；最后一个场景退出后释放共享资源。

目前可修改上衣颜色。旧版装扮字段与 Socket.IO 协议保留兼容，但没有实现换发型、配饰、女孩预设或捏脸，不展示无效控件。Idle 和 Sit 仍为保持姿态；运行时提供动作淡入淡出，尚无完整坐下过程、脚部 IK 或独立布料模拟。头部生成网格的隐藏接缝和局部纹理瑕疵仍待后续美术迭代。两人联机验证不能代替满房 12 人和低端手机的性能验收。
