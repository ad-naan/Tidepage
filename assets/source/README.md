# 制作源文件

这里保存可继续编辑的制作源，不作为网站静态目录，不进入 Web 或 realtime 镜像。

- `characters/cozy-avatar/`：角色 Blender 源和贴图内嵌核对记录；浏览器使用 `public/assets/models/avatars/` 的 GLB。
- `brand/`：品牌母图、概念候选和生成提示词；浏览器使用 `public/assets/brand/` 的发布版本。

概念与评审说明保留在 `docs/art-direction/`；过程下载与试验放入忽略的 `.cache/`。新增资产按根目录 [ASSETS.md](../../ASSETS.md) 登记来源、用途、制作源和运行路径。不要把 `.blend1`、安装包、缓存或检查截图放进运行资源目录。
