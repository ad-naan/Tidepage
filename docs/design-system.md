# Tidepage 设计基础

以纸面、铅笔和海岸余晖为视觉语言。界面要紧凑、清楚，留白服务内容分组；插画与世界场景可以舒展，工具和列表不能随之放大。

## 代码入口

| 入口                                                       | 职责                                             |
| ---------------------------------------------------------- | ------------------------------------------------ |
| `src/styles/tokens.css`                                    | 字体角色、字号、字重、行高、间距、笔触与动效变量 |
| `src/styles/design-contract.css`                           | 现有页面应用这些变量的共同规则；最后加载         |
| `src/shared/ui/typography/Text`                            | 语义标签与视觉字号分离的文字组件                 |
| `src/shared/ui/drawing/PencilDefinitions`、`HanddrawnMark` | 共用静态纸纹滤镜与手绘重描                       |
| `src/shared/ui/feedback/NoticeProvider`                    | 全局操作提醒、页面信息与阅读信息的统一承载区域   |
| `src/shared/config/profile.ts`、`ProfileLinks`             | 个人外链配置与首页入口                           |

新增组件使用 token 或 `Text`，业务内容放在模块内。旧页面样式逐步迁入共同规则；不要继续通过任意全局标签选择器影响导航和组件。

## 字体

| 角色 | 字体包 / 变量                                        | 用法                                 |
| ---- | ---------------------------------------------------- | ------------------------------------ |
| 界面 | Inter Variable + Noto Sans SC Variable / `--font-ui` | 导航、列表、说明、按钮、元数据       |
| 阅读 | Inter + Noto Sans SC / `--font-reading`              | 长文正文、正文标题、列表与表格       |
| 书卷 | Noto Serif SC Variable / `--font-editorial`          | 栏目标题、姓名、文章主标题与引用     |
| 手写 | 现有本地 gardenHand / `--font-hand`                  | 签名、主题彩蛋与少量装饰；不用作正文 |
| 图表 | LXGW WenKai TC 400 / 局部 `--font-diagram`           | 手绘小图的短标签与连线文字           |
| 代码 | Cascadia Code、SFMono、Consolas / `--font-code`      | 代码块                               |

Fontsource 可变字体在根布局引入，自托管 WOFF2、按 Unicode 范围请求子集，使用 `font-display: swap`。不运行时请求 Google Fonts。新增其他文字系统时补充对应字体与回退栈，组件不判断 locale。

图表的手写字体由 `shared/ui/drawing/MiniDiagram` 按需引入，仅使用 400 字重和 Unicode 分片，并以现有界面字体栈补充缺少的字符。`--font-diagram` 限定在图表内，标题、题注与站点正文继续使用各自的字体角色。

正文和普通界面用 400；栏目分组与文章主标题用 500，正文层级标题和明确强调使用 600。界面不使用 300 或浏览器合成的超粗字重。手写字体实际提供 300，限定在上述装饰范围。

## 尺寸与节奏

| 角色               | 字号 / 行高                            |
| ------------------ | -------------------------------------- |
| 微型装饰、辅助数字 | 10px；不承载主要内容                   |
| 元数据、注释       | 11px / 1.55                            |
| 导航、链接、小标题 | 12px / 1.55                            |
| 界面正文、列表标题 | 14px / 1.8                             |
| 文章正文           | 16px / 1.8；窄屏 15.5px / 1.85         |
| 栏目标题           | 22px / 1.5                             |
| 首页姓名           | 48–58px 手写签名；身份行独立为 13–15px |

间距基于 4px：4、8、12、16、20、24、32、40、48。控件内部通常 4–8px，文本组 8–12px，卡片内部 12–16px，区块之间 24–40px。首页文章行最小高度 72px、上下内边距 12px，摘要收为一行。不要给短标题配固定的大面积占位。

页面共用 `--site-content-max` 与 `--site-gutter`，版心最大 1320px；文章阅读列保持适合阅读的行长，并在同一版心内布置目录。滚动页头是独立的悬浮工具，最大 1080px。窄屏按内容换行，不压缩文字到难读尺寸、不让工具溢出 SVG 背景。

## 线条与表面

语义控件细边框可用 `--stroke-ui: 1px`。装饰线使用 SVG 曲线、1.35 的主笔触与较淡的重描；强调笔触 1.8。共用 `tidepage-pencil` 静态纸纹，不逐帧更新噪声，不把文字、头像或焦点轮廓做成模糊笔触。

选中项用 `HanddrawnMark`；不加常规直线下划线。页头第二形态用完整闭合的不规则 SVG 轮廓、晕染填色与背景柔焦，四边都要自然。第一形态融入背景，无悬浮阴影。页头保留晚霞与云岸，不另画太阳或月亮，与首页插画分工。

导航预览和作者状态使用 `AnchoredPanel` 的 `paper` 表面，复用 `PencilFrame` 的纸边。导航以入口居中定位，距离页头 6px，靠近屏幕边缘时收进可视范围；作者状态与入口左侧对齐。预览以分组标题、内容和底部入口构成，文章标题与日期上下排列，手记摘要最多三行。首次悬停等待 160ms，栏目之间切换等待 70ms，离开后保留 260ms 穿越间隙；尺寸与位置平滑过渡，减少动态效果时直接切换。点击入口和键盘展开仍保留独立的焦点及关闭行为。

浮层的栏目标题配一枚 `CoastGlyph`，正文和入口之间用 `PencilLine` 的浅色潮痕分隔，纸面只带轻微暖色与角落铅笔记号。菜单悬停用不规则淡晕染，当前入口保留 `HanddrawnMark`；键盘焦点复用全站的铅笔潮线，不另画外部虚线框。状态面板沿用相同页眉与分隔笔触，应用图标和正文不加滤镜，不堆叠装饰卡片。深色模式使用现有夜色变量和暗投影。

## 提醒与页面信息

```tsx
const { notify } = useNotice();
notify({ title: t("saved"), tone: "success" });
notify({
  title: t("failed"),
  detail: t("retryHelp"),
  tone: "error",
  duration: 6500,
});
```

提醒位于头像右侧，以铅笔括注和不规则纸色晕染呈现。标题用简短的动作结果；长句放 `detail`，向下展开，不能撑高 header。当前只显示最新提醒，防止多条堆积遮挡内容。默认 4.2 秒，悬停、聚焦或文档隐藏时暂停；支持关闭按钮和 Escape。成功/普通消息用 polite live region，错误用 alert，显示区域不重复播报。

`usePageNotice({key,title,eyebrow})` 注册栏目信息；详情页把 `ReadingProgress` 作为 `NoticeDock` 的 context。操作提醒暂时替代信息，结束后恢复。清理按 key 判断，旧页面不能清空新页面的信息。窄屏隐藏常驻信息，操作提醒在头像下方展示；无 header 的场景使用同一风格的底部回退位置。

## 个人介绍与外链

首页依次显示问候、姓名、全栈与 UI/UX 身份、创作理念、文章与外部入口。外链是透明的页边注脚：图标、名称与小箭头；悬停或键盘聚焦时描出铅笔线、淡晕染与说明。星芒仍可切换主题文案，不自动轮播、不让页面跳高。

所有文案在各语言 JSON 的 `home.hero`、`home.social` 与 `feedback` 中；外链地址在 `profileLinks` 集中配置。新增语言必须补齐同构词典，禁止在 JSX 内写 locale 三元表达式。

## 动效与可访问性

内容加载只显示与内容布局一致的骨架，不在骨架下方叠加加载小字或转圈。`LoadingSkeleton` 延迟播报的状态文案仅供读屏使用；错误和重试仍明确显示在对应内容区域。

大图先露出纸色底，较慢的请求只做一次轻微的纸色变化。解码完成后，图片用约 280ms 的透明度过渡显现，缓存命中直接显示。错误时保留图片位置和替代文字；启用减少动态效果时，纸面和图片直接切换。小头像与图标沿用各自的尺寸和底色，不铺大面积占位。

照片廊按窗口宽度使用两到四列。照片按公开顺序填入当时最短的列，保留图片比例和题注；继续加载时只向已有布局追加照片。

工具反馈约 180ms，普通柔和过渡约 380ms。按钮按压和锚点浮层使用接近临界阻尼的弹簧，阻尼比 `ζ = c / (2√km)` 约为 1。按钮的缩放幅度小，浮层用短位移交代来源，透明度单独收尾。唱臂和首页彩蛋可以稍柔和。连续点击时，当前运动应能转向新目标，搜索图标和对话框不需要等旧状态演完。参考 [Apple 的弹簧动画讲解](https://developer.apple.com/videos/play/wwdc2023/10158/)、[iPhone 手势与可中断动效案例](https://developer.apple.com/videos/play/wwdc2018/803/)及 [Material 的空间与效果弹簧](https://m3.material.io/styles/motion/overview/how-it-works)。

页头形态切换只提交一次目标布局，再分别缩放纸面图层、平移文字与控件，保留连续滚动时的中途转向；不要逐帧过渡 `width` 或用 `max-width` 截断过渡。自定义滚动条复用尺寸测量，普通滚动只移动滑块并同步无障碍数值；拖动与键盘滚动显式使用即时行为，避免全站平滑锚点滚动造成滞后。隐藏的夜景装饰和离开视口的插画动画暂停。

触屏使用系统滚动和惯性，桌面保留可拖动、支持键盘的滚动条。插画中持续移动的飞鸟有独立合成层，离开视口即暂停。播放器等持续反馈优先移动或缩放已有图层。触屏 3D 场景限制画布分辨率与阴影贴图大小，拖动镜头时缩短跟随滞后。排查掉帧时分别记录布局、绘制和 WebGL 渲染，并在相同视口、输入和节流条件下对照。参考 [Chrome 的高性能动画指南](https://web.dev/articles/animations-guide)。

尊重 `prefers-reduced-motion`，停用对应的装饰位移、描线与循环动画。可点击控件保留可见焦点、明确标签与真实链接语义。装饰 SVG 不进入读屏顺序，浮层使用 Portal 与共享交互边界。

富文本 h2 / h3 / h4 使用阅读字体 25 / 21 / 18px、600 字重；长文主标题保留书卷字体与 500 字重。引用使用书卷字体，评论通过共用渲染器 compact 模式缩放，不覆盖全局正文样式。

## 首页插画与阅读记录

首页保留原有的介绍与海岸插画、左手记右文章结构，不增加桌面物件区或重复便笺。纸船悬停或键盘聚焦仅横移 4px，180ms 返回，点击立即进入海岸漫游；触屏常驻显示入口说明。水獭使用用户提供的圆脸暖棕参考生成的透明逐帧素材：平时为静态 PNG，点击后播放透明 WebP 精灵图中的八帧，逐帧保留源 GIF 时长，结束恢复同一静止帧。静帧与精灵图保持挂载，加载完成前保留静帧；连续点击从头播放，不重新请求图片、不排队。`scripts/build-otter-sprite.py` 从源 GIF 生成精灵图与时长数据，并校验每帧像素一致。减少动态效果时只切换挥爪静帧。日月按钮复用共享主题设置，与页脚控件和系统主题保持同步。收藏与摘录使用直接文案，不附加折角、描线或气泡。

手记、项目、一言、相册的页眉线稿各有一处主动触发的彩蛋：落叶、灯塔光束、纸飞机和照片内的小鸟。只移动原插画的局部，不移动文字，不覆盖页面，也不改变内容或筛选。动作约 2 秒，2.2 秒恢复静态；再次触发从头播放，不排队。按钮保留键盘焦点，窄屏也有至少 44px 高的入口；无常驻可见提示，读屏名称说明动作。减少动态效果时只显示静态风线、光束或小鸟，结束直接恢复。

手账是 `/journal` 独立页面：桌面为目录与正文的双页纸本，窄屏为单页，装订线、页码和叠纸构成阅读表面。保留正常导航、浏览器返回与整页滚动，不使用遮罩或焦点锁定。目录和前后页立即响应，正文仅有 180ms 的淡入及 3px 位移，减少动态效果时禁用；不模拟卷纸翻页。取出条目后焦点留在持续存在的书页区域。章节书签复用阅读测量，不另建滚动监听；返回同一个章节链接也须恢复滚动位置。作者补记以铅笔边注呈现，使用 Disclosure 的原生展开行为和短透明度过渡。新增补记聚焦正文，移除后回到新增按钮。

## 日期与时间

统一使用 `shared/lib/date-time` 和 `DateTime`。时间点按 `site.timeZone`（Asia/Shanghai）展示；只有日期的值保留原日历日期，不参与相对计算。无时区的时间字符串不猜测浏览器所在时区。

- 评论使用 `mode="activity"`：一分钟内“刚刚”，一小时内按分钟，一天内按小时，七天内按天；满七天显示月日，跨年补全年份。未来时间显示完整日期和时间。
- 文章、手记、导航和归档使用绝对日期；后台修改时间、航行日志等需要核对顺序的记录使用 `mode="datetime"`。表单继续使用 DatePicker。归档的日/月装饰列可用 `layout="calendar"`，完整日期保留在提示和无障碍名称中。
- 相对时间通过原生 `time` 保留 ISO 时间，悬停提示完整日期、时间及 UTC 偏移；中英文由 Intl 和语言目录共同提供。无效时间显示统一占位。
- 所有相对时间共享一个分钟刷新时钟，页面隐藏时暂停；服务端和首次 hydration 先使用相同的绝对时间，避免时间差引发 hydration 不一致。不要为每条评论创建计时器。

## 四季与晨昏背景

页面边缘由暖光、雾蓝和潮汐反光构成三层低对比度底色，漂移周期为 54–96 秒，中央阅读区域保持通透。按站点上海时区自动切换清晨（5–8 点）、白昼（8–17 点）、黄昏（17–20 点）和夜晚；光源依次偏向左上、上方、右侧和月光位置。晨昏配色独立于用户选择的浅色 / 深色主题。

春季（3–5 月）是花瓣、柳叶与桦叶，夏季（6–8 月）是青绿柳叶、橡树叶与桦叶，秋季（9–11 月）以赭红枫叶和金色银杏为主，搭配圆裂橡树叶、锯齿桦叶与细长柳叶，冬季（12–2 月）是疏落的小雪花。使用共用绘画组件的实心轮廓与细叶脉，桌面最多 18 枚、手机最多 8 枚；大小、落点、速度与翻转周期错开，覆盖整个页面，包括中央区域。飘落层在内容下方，不拦截操作；文章与专注阅读进一步减淡。

桌面指针接近时，叶片轻轻偏转、让开后回落；光雾有最多横向 12px、纵向 8px 的缓慢视差。指针停下且回落结束后停止 JS 更新。不绘制随机曲线或点击图形，不追踪触屏手指，不改变正文位置。

页脚“背景”提供“缓动 / 静止”，本机记住选择。隐藏标签页、系统减少动态效果或高对比度模式停止持续绘制；海岸漫游的独立场景不挂载这层背景。暂停保留当前画面，恢复沿原来的节奏继续。

## 聚焦与书写状态

全站焦点由 `src/styles/focus.css` 统一绘制，页面 CSS 不再定义自己的 `outline`。按钮、链接和 Disclosure 的键盘焦点使用底部短潮线与很淡的纸面晕染；沿用 PencilLine 的双笔描线，不改变控件尺寸，也不盖住指针或文字。实心按钮使用反色笔迹。

输入框、多行输入、Select 与 DatePicker 在书写边缘显示较长的铅笔线；裸输入保留透明背景。组合搜索框用 `data-focus="integrated"` 把提示交给外层已有的 PencilLine，聚焦时加深主笔，避免输入本身和容器重复绘制。富文本正文以左侧铅笔边注提示编辑位置。

`--focus-ink` 与潮线图案分别定义浅色棕墨和深色月光色，正常交互不显示外部虚线。滚动媒体、上传、滑块及场景热区保留完整实线边界。高对比度模式使用系统 Highlight 实线，确保禁用图像和阴影时仍有可见焦点。反馈即时出现，无循环、闪烁或位移动效，减少动态效果时保持相同静态提示。
