# 海岸与海湾

`/{locale}/explore` 使用一个持续存在的场景。落日海湾、海面和三座离岸小岛共用坐标、角色、昼夜与探索进度；上下船不卸载页面或重建角色。

## 海湾

点击地面寻路，WASD / 方向键行走，拖动环顾。玩家可以走到长椅、小屋、野餐点，挥手、落座、调整上衣颜色并下载当前画面的 PNG。照片只包含三维场景，由用户保存到本机。

人物使用 `public/assets/models/avatars/cozy-avatar-v1.glb`，制作源、动作和已知限制见 [角色说明](../assets/source/characters/cozy-avatar/README.md)。海湾景观由程序生成。模型尚未支持捏脸、换发型或配饰；界面不展示这些无效选项。

启动独立实时网关后，可同步同一海湾内的同行者、位置、动作和合照邀请。登录身份通过服务端签发的票据进入房间，站长标识校验管理员账号。地点打卡与合照元信息可保存到账号手账，照片文件仍留在本机。配置和协议见 [实时服务](realtime.md)。

## 群岛航海

走近船按 E 登船，靠近码头或沙滩按 E 下船。船保留在实际停靠位置，回到船旁才能再次登船。指南的登船按钮会先步行到船旁；航行时点击岛屿目的地会规划到可登陆的岸边，上岸后可继续步行进入岛内。WASD / 方向键也可直接驾驶。

拾贝岛、海湾小屋和风帆岛各有一枚灯芯，集齐后前往海岸灯塔点灯。夜间可在星落岛发现隐藏地点。沿用 `coast-journey-v1` 存档，旧航海进度无需重置。旧 `CoastalExperience` / `createCoastScene` 已不由探索入口加载。

发现进度保存在当前浏览器。声音默认关闭，用户操作后启用；页面隐藏时停止渲染和音频，降低动态效果设置取消持续环境动画与镜头缓动。小屋使用带真实门洞的墙体，进入后隐藏屋顶；已移除不存在的池塘、小屋和庭院长椅碰撞。

实时网关的 `movementVersion: 3` 校验上下船距离、岸线和船速，并广播停船位置和移动方式。发布时需要同时更新并重启实时网关。旧网关仍兼容步行，但航行会提示更新网关或离开联机；不能假装航行成功后再被服务器拉回。

## 仰望天空与场景对话

拖动镜头向上，或按 I / K 抬头、低头，V 在天空视角与原视角间切换。镜头可以看到接近头顶的天空，抬头不会把相机旋转到地下；太阳、月亮、星群和银河保持在远方，不会因驶离海湾而穿过星空。

水獭和海龟常驻海滩。走近水獭按 E，或者用指南中的“走到水獭身边”实际寻路过去。发言以跟随角色的场景气泡出现，输入时只显示底部的简短输入栏，没有独立聊天窗口或聊天记录面板；关闭后恢复原镜头。自由对话要求启用模型功能并登录，最多发送最近三轮对话以及当前位置、昼夜，切换账号会清空本地上下文。

按 Enter 或动作栏的说话按钮向附近玩家发言。登录并加入同行后，服务器使用真实身份、实际位置校验消息，只有发言处和说话者附近 12 米内的旅人能收到，20 秒后过期；每个账号每 10 秒最多三句，一句最多 180 字符。断线会清理气泡，不持久保存聊天记录；气泡可暂时静音。文字按纯文本显示，不解析 HTML。`speechVersion: 1` 单独协商，旧客户端继续收到原有快照；旧网关仍能行走，但聊天会提示更新。发布需重启实时网关。

在水獭身旁点击“听水獭和海龟聊聊”，可以用输入栏中的话作为话题，留空时聊当前昼夜的海湾。两个 AI 轮流发言，服务器固定角色身份，下一次生成收到前面实际完成的回复，一次最多四轮，不会无限自动调用。玩家可停止或结束旁听；关闭、切换页面、隐藏页面会取消未完成请求与后续轮次。AI 对话只在发起者的场景里播放，不广播给其他玩家；公开玩家聊天不会发送给 AI 模型。

自动化覆盖跨网关附近消息投递、远处隔离、身份与频率校验、旧客户端兼容、消息过期，以及 AI 顺序、上下文传递、取消后不再生成。气泡布局仍需在浏览器实测；本次 Windows 浏览器控制因无法可靠识别网址而停止，未完成本轮画面验收与真实模型端到端验收。

## 维护入口

| 内容                     | 文件（相对 `src/modules/world/`）                                  |
| ------------------------ | ------------------------------------------------------------------ |
| 海湾边界、地标和碰撞     | `domain/coast-harbor.ts`                                           |
| 共用岸线、岛屿与地面高度 | `domain/harbor-terrain.ts`                                         |
| 同一地图中的探索地点     | `domain/harbor-journey.ts`                                         |
| 海湾场景和控制           | `runtime/createHarborScene.ts`、`runtime/createHarborLandscape.ts` |
| 角色加载与共享资源       | `runtime/coastAvatarAsset.ts`、`runtime/createCoastAvatar.ts`      |
| 海湾界面                 | `ui/HarborView.tsx`                                                |

改地标尺寸时同步检查碰撞与寻路。模型编辑遵循 [素材约定](../ASSETS.md)，不要将制作源写入 `public`。

运行 `pnpm run check` 和 `pnpm run build`。浏览器需检查步行、进入小屋、登船、航行、登岛、回船、返航、昼夜和手机布局；多人变化需两个独立会话联调。单人浏览器验证与 Socket.IO 测试不代表已完成多人浏览器、12 人满房或低端手机性能验收。
