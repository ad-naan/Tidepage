# 海岸与海湾

`/{locale}/explore` 默认进入落日海湾；指南内可以切换到群岛航海，再返回海湾。

## 海湾

点击地面寻路，WASD / 方向键行走，拖动环顾。玩家可以走到长椅、小屋、野餐点，挥手、落座、调整上衣颜色并下载当前画面的 PNG。照片只包含三维场景，由用户保存到本机。

人物使用 `public/assets/models/avatars/cozy-avatar-v1.glb`，制作源、动作和已知限制见 [角色说明](../assets/source/characters/cozy-avatar/README.md)。海湾景观由程序生成。模型尚未支持捏脸、换发型或配饰；界面不展示这些无效选项。

启动独立实时网关后，可同步同一海湾内的同行者、位置、动作和合照邀请。登录身份通过服务端签发的票据进入房间，站长标识校验管理员账号。地点打卡与合照元信息可保存到账号手账，照片文件仍留在本机。配置和协议见 [实时服务](realtime.md)。

## 群岛航海

从码头驾船出发，在漂流湾、海边小屋和工坊收集三枚灯芯，点亮灯塔。夜间可寻找星落湾的隐藏地点。点击目的地自动规划航线，也可用 WASD / 方向键驾驶，靠近地点按 E 交互。

发现进度保存在当前浏览器；指南提供重新开始。声音默认关闭，用户操作后启用；页面隐藏时停止渲染和音频，降低动态效果设置取消持续环境动画与镜头缓动。

## 维护入口

| 内容                 | 文件（相对 `src/modules/world/`）                                  |
| -------------------- | ------------------------------------------------------------------ |
| 海湾边界、地标和碰撞 | `domain/coast-harbor.ts`                                           |
| 海湾场景和控制       | `runtime/createHarborScene.ts`、`runtime/createHarborLandscape.ts` |
| 角色加载与共享资源   | `runtime/coastAvatarAsset.ts`、`runtime/createCoastAvatar.ts`      |
| 海湾界面             | `ui/HarborView.tsx`                                                |

改地标尺寸时同步检查碰撞与寻路。模型编辑遵循 [素材约定](../ASSETS.md)，不要将制作源写入 `public`。

运行 `pnpm run check` 和 `pnpm run build`。浏览器需检查步行、落座、切换航海、昼夜、暂停和手机布局；多人变化需两个独立会话联调。当前双人验证不代表已完成 12 人满房或低端手机性能验收。
