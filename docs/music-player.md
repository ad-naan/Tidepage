# 在线音乐歌单

管理员在「后台 → 站点设置 → 音乐」配置在线歌单。音乐配置全站共用，不随界面语言切换；默认关闭，未指定任何人的歌单。

前台播放器向所有访客开放，无需登录或管理员身份即可读取公开歌单、播放音乐和查看歌词。歌单配置与后台测试仍仅管理员可操作；播放由访客主动点击触发，不自动发声。

1. 选择网易云音乐或 QQ 音乐，填写公开歌单的数字 ID。
2. 默认接口为 `https://api.injahow.cn/meting/`，可以替换为自己的 HTTPS Meting 接口基础地址。程序添加 `server`、`type=playlist`、`id` 查询参数。
3. 点击「测试歌单」查看歌曲数量和前五首标题。测试不保存配置，也不代表所有歌曲都能完整播放。
4. 开启在线歌单并保存，刷新前台。播放器保留唱片界面、切歌和音量，点击播放才会发声。

配置沿用 `site-settings` 工作记录的持久化与版本冲突检查，不需要数据库迁移。公开读取只使用管理员记录，作者的私人草稿不会改变全站歌单。旧设置没有 `music` 字段时按默认关闭处理。

`GET /api/v1/music` 返回配置对应的标准化歌曲列表；`POST /api/v1/music/preview` 仅允许同源的管理员请求，并限流。服务器固定已校验的公网 DNS 地址，每次重定向重新校验，只请求 HTTPS JSON；最多读取 2 MiB，超时 12 秒，最多处理前 1000 条记录。非 HTTPS 播放地址不进入播放列表。

每个服务进程按接口、平台和歌单缓存结果五分钟，合并并发请求；失败缓存十五秒。保存不同配置立即使用不同缓存键。歌曲本身不经本站代理或缓存，浏览器直接访问服务返回的音频与封面地址。

公共服务和曲目播放受服务维护、区域、版权及会员限制影响。读取失败时播放器显示重试入口；单曲失败时显示提示，可切换下一首。部署时应实际验证所选服务在服务器和访客网络中的可达性，尤其是 QQ 音乐。

## 歌词与播放交互

导航栏显示歌名与当前一句歌词，换句淡入，下方细线显示当前句的进度；唱片按钮独立控制播放/暂停，点击歌词展开播放器。窄屏保留紧凑的两行显示，保持导航栏高度与宽度稳定。键盘打开后焦点进入内容切换，关闭后由共享浮层恢复焦点。

播放器默认展示歌词页，当前句保持居中，前后文以较轻字色和上下渐隐呈现。滚轮、触摸或键盘浏览会暂停自动跟随；「回到当前句」恢复。点击有时间标记的歌词跳转到该句，保持原来的播放/暂停状态。方向键与 Home/End 可以浏览，Enter/Space 激活。无时间歌词只阅读、不跳转；无歌词和读取失败分别显示说明和重试入口。减弱动态偏好停用位移与平滑滚动。

「待播」页展示歌单，可选曲；播放模式按钮依次切换列表循环、单曲循环、随机播放，并记住浏览器偏好。随机下一首不会重复当前曲目，上一首返回实际播放历史。单曲循环只影响自动续播，手动切歌仍可选择其他歌曲。本地文件导入入口已移除。

歌词使用 Meting 返回的 `lrc` 地址。公开列表返回不透明歌曲标识，`GET /api/v1/music/lyrics?track=…` 仅为已配置歌单中的歌曲读取歌词，不接受任意 URL。HTTPS、DNS、重定向规则与歌单请求一致，歌词限制 256 KiB、8 秒，成功缓存十分钟，失败缓存十五秒。LRC 支持多时间标签、毫秒偏移、空白间奏、同时间双语行；没有逐字时间数据时不会伪造逐字卡拉 OK。
