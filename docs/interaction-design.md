# 光阴海岸交互设计

海岸是一处可航行、可发现秘密的空间。正常游玩时让环境占据画面，博客的阅读界面保持独立。水獭、灯塔和海湾承担世界里的角色，内容分类不再作为漂浮菜单覆盖场景。

## 当前可玩的航程

玩家从码头驾船出发，在漂流湾、海边小屋和工坊各找到一枚灯芯。三枚灯芯集齐后才能点亮灯塔。切换到夜晚，蓝色航迹和星落湾出现；驶入石拱附近触碰星光，完成本次探索，点亮湾内的星座。

点击海面或岛屿会规划避开岸线的航路，WASD 和方向键可手动航行。拖动环顾，向上拖动可以仰望星空，滚轮调整距离。靠近地点后才显示交互提示，按 E 或点提示触发。指南内保留辅助航线，便于触屏和键盘用户抵达各处。

三枚灯芯、灯塔和秘密地点的发现状态保存在当前浏览器；航行位置不保存。指南中可重新开始。当前是一段探索解谜闭环，没有战斗、角色步行、建筑内部或多关卡系统。

## 环境表现

昼夜共享光源方向。夕阳、月光、程序化云层和银河参与天空渲染；海面通过实时平面反射映出建筑与天空，再由多尺度波纹法线扰动倒影。船移动时产生局部尾迹，夜间呈蓝色荧光。星点具有不同亮度、尺寸与缓慢闪烁。

建筑保留灯塔栏杆、屋顶瓦片、窗框、码头绳索等近景细节。岛岸和植被使用程序化几何。现阶段的模型仍偏风格化，海面为平面反射与法线波纹，并非完整流体模拟或扫描级写实资产。

阅读页使用独立的全页夕照或月光晕染。页头不再重复叠加光晕，避免矩形色带。页头展开面板只允许纵向滚动，自定义滚动条在内容完整展开后才出现。

## 界面和动效规则

常驻界面仅保留返回、指南、声音、昼夜、暂停，以及角落的任务进度。操作提示首次短暂出现，线索和结果采用短通知；没有大标题、文章卡片和分类导航。较长说明放进可关闭的指南。

声音默认关闭，用户点击后启用。暂停会停止航行和环境时间；打开指南停止航行；页面隐藏时停止渲染并暂停音频。减弱动态设置关闭环境持续动画并取消镜头缓动，同时保留主动航行能力。

## Agent 接入方向

Agent 可成为水獭的行为与对话来源，了解已经发现的线索，并按需提供提示、推荐下一处可探索地点。先展示角色动作、目光或光线指引，再在用户主动交谈时展开简短对话。

接入时由服务端产生受限意图，例如建议航向、解释当前线索、切换时间。客户端校验地点和前置条件，执行现有导航及交互状态机。Agent 不能直接跳过收集条件、执行任意 JavaScript，或在用户航行中突然抢走镜头。任何自动航行都应能被手动输入立即取消。

本轮只实现前端世界、交互规则和持久化进度，没有连接模型服务、对话接口或长期记忆。

## 验证入口

运行 `npm run typecheck`、`node --test tests/coast-journey.test.mjs` 和 `npm run build`。规则测试覆盖解锁条件、重复收集、损坏存档，以及所有停泊点之间不穿岸的航线。浏览器检查覆盖完整航程、昼夜、隐藏地点、暂停和手机布局；画面效果仍需通过实际 WebGL 截图判断。
