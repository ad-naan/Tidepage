# 工作台实现与后续边界

入口：`/zh-CN/admin`、`/en/admin`。当前为前端本地工作区：没有真实站主登录、生产发布、在线上传或模型调用。本地保存不代表服务器内容已改变。

## 已实现

- 桌面固定外壳，导航与内容分别滚动；手机自然页面滚动。后台跳过前台整页过场，动态内容路由按栏目挂载，避免旧列表闪到新栏目。读屏提示区固定定位，避免在文档末尾多撑一像素。
- 文章：新建、跨语言标题搜索、编辑、本地保存、刷新恢复、版本冲突检查、回收站和恢复。公开文章可以建立独立工作副本，不能直接删除公开来源。
- 手记、项目、一言、照片廊：页面内分组编辑、语言版本、公共字段、本地保存、删除和恢复。友联有独立本地管理界面；评论管理等待身份与互动服务。
- 站点设置：语言版本和本地工作副本，头像 / 分享图选择媒体资源；不修改运行配置或 UI 词典。
- 共享文件选择、日期时间日历；Dialog 标题固定，内容内部滚动，滚动条在纸面内侧；Select Portal 在 dialog 内保持正确层级。

## 字段与国际化

界面语言来自注册 catalogs；内容语言独立选择。同一 id 下各语言分开保存，缺少英文时不以中文正文回填。

| 内容     | 共用字段                                                                                                                   | 按语言保存                                                           |
| -------- | -------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------- |
| 文章     | id、schemaVersion、revision、author、category、sketch、coverAssetId、publishedAt、minutes、createdAt、updatedAt、deletedAt | title、slug、excerpt、body、tags、seoTitle、seoDescription、coverAlt |
| 手记     | id、revision、内容日期、排序、分类、插画、更新时间、回收站状态                                                             | 正文、心情、标签                                                     |
| 项目     | id、revision、排序、分类、插画、色调、内容日期、更新时间、回收站状态                                                       | 名称、副标题、介绍、展示状态、技术栈输入                             |
| 一言     | id、revision、排序、内容日期、更新时间、回收站状态                                                                         | 文本、出处 / 作者                                                    |
| 照片廊   | id、revision、assetId、分类、排序、内容日期、更新时间、回收站状态                                                          | 标题、说明、替代文字、地点                                           |
| 友联     | id、revision、url、category、sortOrder、deletedAt                                                                          | 站名、介绍                                                           |
| 站点配置 | revision                                                                                                                   | 公开资料、自述、首页和分享文案、资源引用与当前语言的说明             |

这些是前端 DTO。接后端前仍需正式校验技术栈数组、导航可选值、自述分节、日期时区与发布修订；本地工作副本与前台 draft / published 分开，修订模型完成后才开放“更新发布”。

## 富文本

`content/domain/editor-document.ts` 定义版本化草稿与支持的节点 / marks；正文以 ProseMirror JSON 为事实来源，不同时维护 Markdown / HTML 正文。`legacy-draft.ts` 导入前台分节结构，测试覆盖电影原片名、导演、年份、封面与说明，网页站名与图片，以及提示块和代码说明的保留。

Tiptap 实例独立于外层表单，不在每个输入事务把整篇 JSON 写进 React state。各语言保留自己的实例、选区和撤销历史，预览不销毁编辑实例；只在保存和显式快照时序列化。依赖依据：[Tiptap 性能指南](https://tiptap.dev/docs/guides/performance)。

已接入基础格式、标题、列表、待办、引用、代码、表格、图片与来源卡片，支持 Markdown 输入快捷方式和选区浮动工具。`/` 菜单靠近光标定位，不挤动正文。图片可调整宽度、拖动尺寸、对齐、填写说明、替换、裁剪与恢复原图。

编辑画布使用工作区可用宽度；标题和正文为主区，属性（包括摘要、SEO、封面与发布设置）和 AI 从页头按需展开，避免永久挤占写作空间。常用格式留在工具栏，插入菜单与斜杠菜单复用内容块定义，支持中英文关键词筛选、方向键和回车；Escape 收起菜单并恢复入口焦点。图片操作浮在图片内侧，选中后显示，尺寸 / 对齐 / 替代文字 / 说明集中到图片设置弹窗。

后台路由与本地数据初始化复用 `shared/ui/loading/LoadingSkeleton`；骨架在 180 ms 后显现，短请求不闪加载文案，500 ms 后才进行读屏播报。降低动态效果时取消循环动画。导航预取完整后台路由（Next 仅在生产启用预取），共享页头、侧栏和工作区滚动容器保持挂载。

音乐目前为来源卡片，不加载第三方播放器；电影与网页资料手动录入，不自动抓取。部分历史元数据能保存但尚无高级编辑控件。多人协作、评论锚点、完整版本历史、离线自动恢复日志、公式、图表、多列及全部块拖拽尚未实现，不能宣称达到成熟文档产品的完整体验。

## 资源与上传

`media/domain/assets.ts` 定义 ImageUploader。Blob 存入 IndexedDB，正文只保存 assetId；object URL 只在显示时生成，卸载时回收。允许 JPEG / PNG / WebP / GIF，单张最多 12 MB，每边最多 20000 像素。

裁剪使用 [React Easy Crop](https://github.com/ValentinH/react-easy-crop)，生成新 PNG，不覆盖原 Blob。正文保存 originalAssetId，可恢复原图，撤销也保留旧引用。最长输出边 4096 像素，GIF 裁剪为静态图，界面有说明。媒体回收站只取消可选状态，不删除被引用的 Blob。

后续上传适配器须接鉴权、签名 URL、进度、取消、重试、对象存储及服务端检查，不能只信浏览器 MIME。

## 流式创作

`ai/domain/writing.ts` 定义输入、delta / done 事件。HTTP 适配器只接受同源端点；SSE 解析器支持 UTF-8 跨块、CRLF、多行 data 和 AbortSignal，缺少 done 视为中断。provider 密钥不进浏览器。

当前 UI 使用明确标注的示例流，验证生成、停止、重试、插入与替换。建议不会直接写入正文；采纳前对比生成开始时的文档，变化后拒绝覆盖。真实 LLM 和工具 Agent 后续单独建设：服务端 provider → 权限 → 上下文预算 → 工具校验 → 事件流 → 前端审阅采纳。

## 验证与推进

运行 `pnpm run check`、`pnpm run build`；浏览器验证双语独立正文、跨语言撤销、刷新恢复、冲突、图片插入 / 裁剪 / 对齐、流式停止、未保存离开、回收站恢复、Dialog 长短内容、日历键盘及桌面 / 手机。

先稳定前端，再按模块推进身份授权、内容修订发布、资源服务和创作 Agent。公网使用前需真实后台鉴权；目前 UI 没有修改服务器数据的能力。
